# Website Redesign Rollout – Project Documentation

## 1. Project Overview

Website Redesign Rollout is a hands-on Agile project management portfolio project created using Jira Software. The objective is to organize and track website redesign activities through Agile Scrum practices, work items, custom workflows and automation.

## 2. Project Objectives

* Organize website redesign requirements.
* Create and manage Epics and User Stories.
* Maintain and prioritize the product backlog.
* Track project progress using Jira.
* Configure custom workflows.
* Implement automation for blocked work items.
* Monitor project activities using Jira reports and timeline views.

## 3. Tools and Technologies

* Jira Software
* Agile Methodology
* Scrum Framework
* GitHub
* Manual Testing Concepts

## 4. Project Workstreams

The project is organized into five major workstreams:

1. UX Research
2. Design System
3. Development Sprints
4. SEO Migration
5. Launch QA

## 5. Agile Implementation

* Created Epics to organize major project activities.
* Added User Stories to define requirements.
* Organized work items in the product backlog.
* Tracked tasks through Jira boards.
* Used Timeline to monitor project activities and progress.

## 6. Custom Workflow Configuration

Configured a Jira workflow with the following statuses:

* Idea
* To Do
* In Progress
* In Review
* Done
* Blocked

This workflow helps track work items throughout their lifecycle and identify blocked activities.

## 7. Jira Automation

Created and enabled automation flows for the project.

**Blocked Automation:**

* Trigger: Work item transitions to Blocked.
* Action: Automatically assigns the work item.
* Action: Adds an automated comment.

**Done Automation:**

* Created and enabled a separate automation flow for Done.

## 8. Project Monitoring

Used Jira project views to monitor:

* Overall project status.
* Backlog and work items.
* Timeline and project activities.
* Completed and pending work.
* Blocked tasks.

## 9. Key Learning Outcomes

* Creating and managing Jira work items.
* Working with Epics and User Stories.
* Managing product backlogs.
* Configuring Jira workflows and statuses.
* Creating automation rules.
* Tracking project progress through Jira.
* Documenting project work using GitHub.

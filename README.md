# Website Redesign Rollout

## Project Overview

Website Redesign Rollout is an Agile project management practice project designed to manage the redesign of an existing website using Jira.

The project follows Scrum methodology to organize development activities, manage requirements, track progress and monitor project delivery.

## Tools & Technologies

* Jira Software
* Agile Methodology
* Scrum Framework
* GitHub
* Manual Testing

## Project Objectives

* Manage website redesign activities.
* Organize requirements using Epics and User Stories.
* Plan and track work through a Scrum backlog.
* Monitor project progress using Jira boards and timelines.
* Configure workflows and automation rules.
* Track blocked tasks and improve task visibility.

## Project Workstreams

1. UX Research
2. Design System
3. Dev Sprints
4. SEO Migration
5. Launch QA

## Jira Workflow

The project uses the following workflow statuses:

* Idea
* To Do
* In Progress
* In Review
* Done
* Blocked

## Jira Automation

Configured automation to:

* Trigger when a work item transitions to Blocked.
* Automatically assign the work item.
* Add an automated comment identifying the Blocked status.

## Project Management Activities

* Created and organized Jira project backlog.
* Created Epics and associated work items.
* Managed sprint planning.
* Configured custom workflow statuses.
* Implemented Jira automation.
* Monitored project progress through Timeline and Summary views.

## Project Outcome

Developed practical experience in Agile project management, Jira administration basics, Scrum backlog management, workflow configuration and automation.
